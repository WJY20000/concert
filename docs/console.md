# 本机控制台

先按项目说明准备本地配置和对应的网页浏览器或安卓设备，然后在项目目录运行以下命令。

```sh
node src/console.mjs config.local.json
```

终端会打印本机浏览器可打开的地址。控制台从配置的 `providers` 读取平台与购票端组合，初始选中配置里的 `provider` 和 `platform`。编辑平台列表后重新启动控制台。场次、票档、座位和观演人由本地配置提供，控制台仅显示运行状态和脱敏时间线。

| 运行方式 | 界面用途 |
| --- | --- |
| 只读检查 | 读取当前页面，检查识别结果 |
| 购票演练 | 进入选择流程，最终提交前结束 |
| 真实购票 | 执行选择与核验，在目标时间后尝试创建待支付订单 |

点击「停止任务」会通知正在运行的子进程结束，进程退出后可启动下一次。关闭浏览器标签只会关掉界面，任务仍由控制台进程管理。若已出现「尝试提交」，请在票务平台核对订单状态后再另起一次购票操作。

时间线以北京时间显示最近 160 条受支持的事件。顶部计时取自运行脚本的时间戳，开售到确认待支付的耗时在核实订单后显示。电脑上应保留终端窗口；需要退出服务时按 Ctrl+C。
